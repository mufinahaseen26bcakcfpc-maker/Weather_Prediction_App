# 🌤️ Zephora – Weather App UI/UX Design

## 📌 About the Project

**Zephora** is a modern and user-friendly weather application designed to provide clear and simple weather information. The app focuses on a clean UI, easy navigation, and a smooth user experience.

This project is a **UI/UX design project created in Figma**.

## 🎯 Objectives

- Provide accurate and easy-to-understand weather information.
- Create a simple and attractive user interface.
- Make weather details easily accessible.
- Provide smooth and intuitive navigation.
- Improve the overall user experience.

## 📱 App Screens

The Zephora weather app contains the following screens:

1. **Splash Screen**
2. **Welcome / Location Screen**
3. **Home / Current Weather**
4. **7-Day Forecast**
5. **Weather Map**
6. **My Locations**
7. **Settings**

## ✨ Key Features

- 🌡️ Current temperature and weather condition
- 💧 Humidity information
- 🌬️ Wind speed
- 👁️ Visibility details
- 📅 7-day weather forecast
- 🗺️ Weather map with radar/satellite options
- 📍 Location-based weather
- 🔎 Manual location search
- ⚙️ Customizable settings
- 🌙 Clean and modern visual design

## 🎨 Design

### Color Theme

The main color used in the application is:

**Primary Color:** `#17357F`

The design uses blue shades to create a calm, trustworthy, and weather-focused appearance.

### Design Principles

- Simple and clean layout
- Consistent colors and typography
- Clear visual hierarchy
- Easy navigation
- User-friendly interface
- Consistent spacing and components
